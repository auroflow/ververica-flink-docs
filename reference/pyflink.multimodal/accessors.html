Accessors#

PyFlink expressions provide image, video, and audio namespaces for invoking multimodal operations with the expression on the left side. The examples below show one way to use them.

Examples:

>>> from pyflink.dataframe import col
>>> df = df.with_column(
...     "thumbnail", col("img").image.resize(width=224, height=224))
>>> df = df.with_column(
...     "frames", col("video_uri").video.extract_frames(max_frames=16))
>>> df = df.with_column(
...     "transcript", col("audio_bytes").audio.asr_whisper())
