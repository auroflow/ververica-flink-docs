pyflink.multimodal.expression.AudioExpressionAccessor.standardize#

AudioExpressionAccessor.standardize(*, sample_rate=16000, channels=1, concurrency=None)[source]#

Standardize waveform sample rate and channel count.

Equivalent to audio_standardize(). See that function for full parameter details.

Parameters

  • sample_rate – Target sample rate in samples per second.

  • channels – Target channel count.

  • concurrency – Optional execution concurrency for this operation. None uses the framework default.

Returns

A DataFrame expression that produces standardized waveform ROW values.
