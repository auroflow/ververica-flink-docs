Data Types#

The DataType class provides factory methods for creating data types used in schema definitions, UDF return types, and other type specifications in the DataFrame API.

Example:

>>> from pyflink.dataframe import DataType
>>> schema = {
...     "id": DataType.int64(),
...     "name": DataType.string(),
...     "score": DataType.float64(),
... }

Variable-shaped Tensor Columns#

Use variable_tensors_to_arrow in an Arrow map_batches function to convert a batch of NumPy arrays into the pyarrow.ExtensionArray required for a tensor output column. Shapes may differ across rows, and None values are preserved. The dtype must match the corresponding DataType.tensor(dtype) field in map_batches return_dtype.

Import it from the DataFrame tensor module:

from pyflink.dataframe.tensor import variable_tensors_to_arrow

Table API Arrow UDFs can import the same implementation from pyflink.table.tensor.

variable_tensors_to_arrow(tensors, dtype)

Convert variable-shaped NumPy tensors to a PyArrow ExtensionArray.
