AI / LLM#

The AI module provides integration with large language models (LLMs) for tasks such as classification, sentiment analysis, text extraction, translation, summarization, PII masking, embedding generation, and vector search. Access these functions through the df.llm accessor on a DataFrame.

Example:

>>> import pyflink.dataframe as pf
>>> pf.set_model_provider(pf.OpenAICompatProvider(
...     task="chat/completions", model="qwen3.6-plus"))
>>> df = pf.from_dict({"text": ["Hello world", "Bonjour le monde"]})
>>> df.llm.ai_translate(
...     "text", source_lang="auto", target_lang="en").collect()

Model Providers#

Register and manage LLM providers.

set_model_provider(name_or_provider[, provider])

Register a global model provider configuration.

set_default_model_provider(name)

Set the default provider lookup name for AI functions.

list_model_providers()

List all registered provider lookup names.

Model Provider#

Base class and built-in provider implementations.

Base class for model providers.

Model provider for all OpenAI-compatible endpoints (openai-compat).

Model provider for Alibaba Cloud DashScope (dashscope).

TritonProvider(*, endpoint[, model_name, ...])

Model provider for NVIDIA Triton Inference Server (triton).

GenericProvider(name, **options)

Generic provider for unknown or custom model providers.

LLM Accessor#

Accessed via the df.llm property on a DataFrame. Provides methods for common AI tasks.

LLMAccessor.vector_search(search_source, ...)

Join this DataFrame with vector search results from another source.

LLMAccessor.predict(*input_cols[, provider, ...])

Perform prediction using a model.

LLMAccessor.ai_classify(input_col, labels, *)

Classify text into one of the provided labels.

LLMAccessor.ai_sentiment(input_col, *[, ...])

Analyze the sentiment of input text.

LLMAccessor.ai_extract(input_col, schema, *)

Extract structured information from text.

LLMAccessor.ai_translate(input_col, ...[, ...])

Translate text from one language to another.

LLMAccessor.ai_summarize(input_col, ...[, ...])

Summarize text to a maximum length.

LLMAccessor.ai_mask(input_col, entities, *)

Mask sensitive information in text.

LLMAccessor.ai_embed(input_col[, dimension, ...])

Generate embedding vectors for text.
