pyflink.table.expression.Expression.trim#

Expression.trim(character: Optional[Union[str, pyflink.table.expression.Expression[str]]] = None) → pyflink.table.expression.Expression[str][source]#

Removes leading and trailing space characters from the given string if character is None. Otherwise, removes leading and trailing specified characters from the given string.
