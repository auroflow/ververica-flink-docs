========
Catalog
========

Functions to register and navigate catalogs and databases used by the
DataFrame API, and to read from or write to catalog tables.

Example::

    >>> import pyflink.dataframe as pf
    >>> pf.create_catalog("my-fluss", {
    ...     "type": "fluss",
    ...     "bootstrap.servers": "localhost:9123",
    ...     "client.security.protocol": "SASL",
    ...     "client.security.sasl.mechanism": "PLAIN",
    ...     "client.security.sasl.username": "*****",
    ...     "client.security.sasl.password": "*****",
    ... })
    >>> df = pf.read_catalog_table("`my-fluss`.my_database.my_table")
