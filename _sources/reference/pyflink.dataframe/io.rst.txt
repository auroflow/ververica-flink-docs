============
Input/Output
============

Functions to read data from external sources into a :class:`~pyflink.dataframe.DataFrame`.
For writing data, see the ``write_parquet``, ``write_kafka``, ``write_odps``, ``write_paimon``,
``write_sls``, ``write_hologres``, and ``write_custom`` methods on
:class:`~pyflink.dataframe.DataFrame`.

Example::

    >>> import pyflink.dataframe as pf
    >>> df = pf.read_parquet("/path/to/data", schema={"id": pf.DataType.int64(), "name": pf.DataType.string()})
    >>> df = pf.read_kafka("localhost:9092", schema={"key": pf.DataType.string()}, topic="my_topic")
