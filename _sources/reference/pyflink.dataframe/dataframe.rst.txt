DataFrame
---------

A :class:`~pyflink.dataframe.DataFrame` is the core abstraction of the PyFlink DataFrame API.
It wraps a PyFlink :class:`~pyflink.table.Table` and provides a pandas-like interface for
data transformations. All transformation methods return a new ``DataFrame`` (immutable/fluent API).

Example:
::

    >>> import pyflink.dataframe as pf
    >>> df = pf.from_dict({"a": [1, 2, 3], "b": ["x", "y", "z"]})
    >>> df.select("a", "b").filter(pf.col("a") > 1).collect()
