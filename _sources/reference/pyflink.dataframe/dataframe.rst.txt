DataFrame
---------

A DataFrame is the core abstraction of the PyFlink DataFrame API. It wraps a
PyFlink Table and provides a pandas-like interface for data transformations.
All transformation methods return a new DataFrame.

Example::

    >>> import pyflink.dataframe as pf
    >>> df = pf.from_dict({"id": [1, 2], "name": ["a", "b"]})
    >>> result = df.select("id", "name") \
    ...            .with_column("id_doubled", pf.col("id") * 2) \
    ...            .filter(pf.col("id") > 0) \
    ...            .rename({"id": "identifier"})
